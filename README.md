# חידון אייל גולן

חידון שירים לטלפון. משחקים לבד בלי אינטרנט, או עם עד עשרה חברים כל אחד מהטלפון שלו.

## הכתובת הקבועה

**https://chenmorr.github.io/eyal-golan-quiz/**

זו הכתובת שנשמרת במסך הבית. היא לא משתנה לעולם, גם אם השרת מתאתחל
או שמנהרת Cloudflare מקבלת שם חדש.

**איך מוסיפים למסך הבית באייפון:** לפתוח בספארי (דווקא ספארי, לא כרום),
ללחוץ על כפתור השיתוף למטה, ולבחור "הוסף למסך הבית". אחרי זה זה נפתח
כמו אפליקציה — בלי סרגל כתובת, עם אייקון משלו.

### איך זה מחובר

| רכיב | מה הוא עושה |
|---|---|
| GitHub Pages | האתר עצמו, על כתובת קבועה. משחק לבד עובד ממנו גם בלי רשת |
| `eyal-quiz` | שרת החדרים על השרת של חן, HTTPS על כתובת ה-tailnet |
| `eyal-quiz-tunnel` | מנהרת Cloudflare שמוציאה את שרת החדרים לאינטרנט |
| `server.json` | יושב ב-Pages ומכיל את כתובת המנהרה הנוכחית |

האפליקציה קוראת את `server.json` כשהיא רצה מ-Pages, וככה היא מוצאת את
שרת החדרים גם אחרי שכתובת המנהרה התחלפה. משחק לבד לא נוגע בזה בכלל.

```bash
npm run url             # כתובת המנהרה הנוכחית
npm run deploy:pages    # בונה, מעדכן server.json ודוחף ל-Pages
systemctl --user restart eyal-quiz          # אחרי שינוי בשרת
systemctl --user status eyal-quiz-tunnel    # מצב המנהרה
node verify-live.mjs    # בדיקה מלאה מול הכתובת החיה
node offline-check.mjs  # מוכיח שמשחק לבד עובד בלי רשת
```

**אחרי שהמנהרה מקבלת שם חדש** צריך להריץ `npm run deploy:pages` כדי
לרענן את `server.json`, אחרת המולטיפלייר לא ימצא את השרת. משחק לבד
ימשיך לעבוד בכל מקרה.

## פיתוח מקומי


ואז נכנסים ל-http://localhost:5173

## הרעיון שמאחורי המערכת

אין קובץ עם שאלות כתובות. יש **טבלת שירים אחת** (`data/songs.json`), ומעליה מחולל
שמייצר שאלות לפי תבניות. מוסיפים שיר לטבלה, ומקבלים עשרות שאלות חדשות בלי לגעת בקוד.

כרגע בטבלה **458 שירים מ-1995 עד 2026**, נמשכו אוטומטית מ-MusicBrainz.

### סוגי השאלות שרצים עכשיו

| סוג | דוגמה |
|---|---|
| שנה | באיזו שנה יצא "מי שמאמין"? |
| אלבום | מאיזה אלבום "לילד הזה התפללתי"? |
| מה קודם | איזה שיר יצא קודם? |
| שיר מאלבום | איזה מהשירים האלה מהאלבום "חלומות"? |
| דואטים | עם מי אייל שר את "להיות אדם"? |
| שיר נושא | איזה שיר נתן לאלבום את שמו? |
| אלבום לפי שנה | איזה אלבום יצא ב-2017? |
| מי לא שייך | שלושה מהאלבום הזה, איזה לא? |

### שני סוגים שמחכים לתוכן

**נחש את השיר מקטע** ו**מאיזה שיר השורה** בנויים במלואם בקוד, אבל לא נדלקים עד
שיש תוכן. אודיו ומילים הם חומר מוגן בזכויות יוצרים, אז אי אפשר למשוך אותם אוטומטית.

להדליק אותם:

1. קטעי אודיו — לשים קבצי mp3 ב-`public/clips/` בשם השיר, למשל `מי שמאמין.mp3`
2. שורות — להוסיף ל-`data/lyrics.json` בפורמט `{ "מי שמאמין": "השורה מהשיר" }`
3. להריץ `npm run data:content`

מארבעה פריטים ומעלה הסוג נדלק לבד בכל החידונים.

## איך המשחק עם חברים עובד

השאלות **לא עוברות ברשת**. השרת שולח מחרוזת קצרה אחת (seed), וכל טלפון מייצר
מהמאגר שכבר יושב עליו את אותן שאלות בדיוק. מה שרץ ברשת הוא רק
"ענה ב', אחרי 1400 מילישניות" — כמה בייטים.

בגלל זה המשחק עובד גם על דאטה סלולרי חלש, וגם אין המתנה בין שאלות.

**הניקוד** בסגנון Kahoot: כל מי שצדק מקבל נקודות, ומי שהיה מהיר מקבל יותר.
לא "הראשון לוקח הכל", כי בחדר של עשרה זה משאיר תשעה בצד בכל שאלה.

**הזמן נמדד בטלפון של השחקן**, מהרגע שהשאלה עלתה על המסך שלו. אם היינו מודדים
בשרת, מי שיש לו אינטרנט טוב היה מנצח את מי שמכיר את אייל גולן טוב יותר.

## דברים ששווה לדעת

**רמת הקושי** נגזרת מכמה פעמים השיר חזר באלבומים ובאוספים לאורך השנים — להיט
נדחס לכל אוסף, שיר צדדי מופיע פעם אחת. הדירוג הוא בתוך כל תקופה בנפרד, אחרת
לשיר מ-2001 היה יתרון של עשרים וחמש שנה על שיר מ-2024. **זה אומדן, לא נתוני האזנה.**

**אופליין** — אחרי טעינה ראשונה כל התוכן יושב על הטלפון. `node offline-check.mjs`
מוכיח את זה: מנתק את הרשת ומשחק.

**הפורט של השרת** נקבע לפי `QUIZ_PORT` ורק אחר כך `PORT`, כי על שרתים משותפים
`PORT` כבר תפוס על ידי שירות אחר.
